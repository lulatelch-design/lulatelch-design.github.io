# Sitio web institucional - I.E. 40028 Guillermo Mercado Barroso

Este paquete contiene una página web educativa completa con:
- Estructura semántica HTML5.
- Estilos CSS3 responsivos.
- Interactividad básica con JavaScript.
- Recursos multimedia locales: insignia, imágenes SVG y video institucional de muestra.
- Criterios de usabilidad y accesibilidad: navegación por teclado, textos alternativos, contraste, menú móvil, etiquetas de formulario y botón de salto al contenido.

## Archivos principales
- index.html: estructura de la página.
- styles.css: estilos visuales y diseño responsivo.
- script.js: menú móvil, modo oscuro, filtros, pestañas, galería, formulario y contadores.
- assets/img: insignia e imágenes de apoyo.
- assets/video: video institucional de muestra.

## Cómo editar en Bloc de notas
1. Abra la carpeta sitio_web_gmb.
2. Haga clic derecho sobre index.html y elija "Abrir con > Bloc de notas".
3. Cambie textos como correo, teléfono, noticias, nombres o enlaces.
4. Guarde el archivo y abra index.html en Google Chrome para ver el resultado.

## Cómo publicar en GitHub Pages
1. Cree un repositorio en GitHub, por ejemplo: pagina-web-gmb.
2. Suba todos los archivos de esta carpeta, respetando la estructura.
3. Ingrese a Settings > Pages.
4. En Branch seleccione main y /root.
5. Espere unos minutos y copie el enlace publicado.

## Recomendaciones para personalizar
- Reemplazar las imágenes SVG por fotos reales de la institución.
- Reemplazar assets/video/video-institucional-gmb.mp4 por un video real del colegio con el mismo nombre.
- Actualizar el correo institucional real en la sección Contacto.
- Agregar enlaces reales de Facebook, Google Classroom, formularios, reglamentos o comunicados.
